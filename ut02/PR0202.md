## Ejercicio 2 - Carga de datasets

```bash
echo "id,make,model,year,price" > vehicle_price_prediction.csv
echo "1,Toyota,Corolla,2020,15000" >> vehicle_price_prediction.csv
echo "2,Ford,Focus,2019,12000" >> vehicle_price_prediction.csv
hdfs dfs -put vehicle_price_prediction.csv /user/ubuntu/proyecto_datos/
```

*Sin salida (éxito)*

## Ejercicio 4 - Organización del proyecto

```bash
hdfs dfs -mkdir /user/ubuntu/proyecto_datos/procesados
hdfs dfs -mkdir /user/ubuntu/proyecto_datos/backup
hdfs dfs -cp /user/ubuntu/proyecto_datos/vehicle_price_prediction.csv /user/ubuntu/proyecto_datos/backup/
hdfs dfs -mv /user/ubuntu/proyecto_datos/vehicle_price_prediction.csv /user/ubuntu/proyecto_datos/procesados/
```

*Sin salida (éxito)*
